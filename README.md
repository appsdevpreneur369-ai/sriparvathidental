# Sri Parvathi Dental Clinic — public website

Public website for **Sri Parvathi Dental Clinic**, Pathur Road Cross, Tadepalle (project code **SPDC**), a ClinicFlow247 **ENTERPRISE (white-label)** clinic.

SPDC is a **website plus a ClinicFlow core tenant**, never a fork of core. This repo is the public site. Staff and patient workflows (super admin, clinic admin, doctor, patient) run on ClinicFlow core, branded for SPDC through the theme tokens in `tenant/sri-parvathi.json`.

Next.js 14 (App Router) · TypeScript · Tailwind · zod-validated content · vitest. Booking is live through ClinicFlow247, with an automatic fallback to an enquiry (and to WhatsApp once a number is confirmed).

## Quick start

```bash
npm install
npm run dev            # http://localhost:3000
npm run check          # lint + typecheck + unit tests + WCAG contrast + production build
```

Build-time settings (`.env.production.local`, or Docker build args; template in `.env.example`):

| Variable | Meaning |
| --- | --- |
| `NEXT_PUBLIC_SITE_ENV` | `production` = indexable; anything else = noindex |
| `NEXT_PUBLIC_SITE_URL` | Canonical base URL (sitemap, OG, JSON-LD) |
| `NEXT_PUBLIC_SHOW_PLACEHOLDER_BADGES` | `true` shows "Draft" badges on unconfirmed content |
| `NEXT_PUBLIC_CLINICFLOW_API_URL`, `…_CLINIC_SLUG` | ClinicFlow247 booking API |
| `NEXT_PUBLIC_PORTAL_BASE_URL` | Portal origin for sign-in/register links |
| `NEXT_PUBLIC_BOOKING_OTP_HINT` | Local/staging only: test OTP hint |

## Where things are

| Path | What |
| --- | --- |
| `content/` | **All** site content. Every record is `approved` or `placeholder`. |
| `src/lib/content/` | zod schemas + loader. A bad content edit fails the build and names the file and field. |
| `src/lib/booking/` | Booking service, ClinicFlow API client, fallback rules |
| `src/app/`, `src/components/` | Pages and UI |
| `scripts/` | Brand assets, image variants, contrast check, tenant file generator, QA tools, `local-stack/` |
| `tenant/sri-parvathi.json` | ClinicFlow247 Enterprise onboarding file (generated by `npm run tenant`) |
| `docs/` | EDITING, BOOKING, LOCAL_STACK, test reports |
| `PENDING_ITEMS.md` | What the clinic still has to confirm |

Start with **`docs/EDITING.md`** to change content, and **`CLAUDE.md`** for project rules.
