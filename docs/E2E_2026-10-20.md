### ⚠ Core finding: report to the ClinicFlow team (not fixable in this repo)

`GET /appointments/{id}/history` for an SPDC patient's appointment returned **200** to:

- **another SPDC patient** (patient B reading patient A's appointment history), and
- **a doctor of a different clinic**.

This is a cross-patient and cross-tenant read of appointment history (an IDOR). It is in ClinicFlow core, which every clinic shares, so the fix belongs in core: scope the endpoint to the appointment's own patient and to staff of that clinic. **This must be fixed before SPDC (or any clinic) goes live with real patients.** It is recorded as OBSERVE rather than FAIL only because the matrix doesn't fail on core behaviour outside this repo.
